# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please contact the maintainer directly privately. Do not open public issues for security vulnerabilities. All reports will be investigated promptly.
